# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion focused on
the work. Harassment, discrimination and personal attacks are not tolerated in issues, pull
requests, discussions or any other project space.

Report unacceptable behaviour privately to the maintainer through GitHub
(**Security → Report a vulnerability** works for confidential reports too). Reports are
handled confidentially, and maintainers may remove content or block participants who break
these standards.
