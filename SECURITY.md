# Security policy

SiteSense handles construction cost data and personal information about site staff, so
security reports are taken seriously.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report privately through GitHub: **Security → Report a vulnerability** on this repository
(private vulnerability reporting). Include:

- what you found and where (endpoint, file, commit)
- steps to reproduce, or a proof of concept
- the impact you think it has

You can expect an acknowledgement within 3 working days and a status update within 10.
Please give us a reasonable time to fix the issue before disclosing it publicly.

## Supported versions

Until v1.0, only the latest commit on `main` receives security fixes.
